# Catalog Storefront — Activities & Activity Steps

| Job Story | Activity | Activity Step | Description |
|-----------|----------|---------------|-------------|
| **JS1** | **Search Catalog** | Submit search query | Submit a keyword or parametric search against the catalog |
| JS1 | Search Catalog | Apply filters | Narrow results by category, specs (voltage, KV, weight, thrust), format, price range |
| JS1 | Search Catalog | Sort results | Order results by relevance, price, rating, or a specific spec value |
| JS1 | Search Catalog | Page through results | Retrieve additional pages of search results |
| JS1 | **Retrieve Suggestions** | Request autocomplete suggestions | Get suggested search terms, categories, or products as the query is typed |
| **JS2** | **View Product Detail** | Request product details | Retrieve full product information including specs, descriptions, and images |
| JS2 | View Product Detail | Request technical documents | Retrieve associated datasheets, CAD files, or compliance certificates |
| JS2 | View Product Detail | Request product pricing | Retrieve current pricing, volume discounts, and any active promotions |
| JS2 | View Product Detail | Request product availability | Check if the product is in stock, on backorder, or discontinued |
| JS2 | View Product Detail | Request product reviews | Retrieve ratings and reviews submitted by other buyers |
| JS2 | **Explore Related Products** | Request compatible products | Retrieve products known to be compatible with the viewed product |
| JS2 | Explore Related Products | Request similar alternatives | Retrieve products in the same category with similar specifications |
| JS2 | Explore Related Products | Request frequently bought together | Retrieve products commonly purchased alongside the viewed product |
| **JS3** | **Compare Products** | Submit products for comparison | Provide a set of product identifiers to compare |
| JS3 | Compare Products | Retrieve comparison matrix | Get a structured comparison of shared and differing specifications |
| **JS4** | **Check Compatibility** | Submit component set | Provide a list of selected components (e.g., motor + ESC + propeller + battery) |
| JS4 | Check Compatibility | Retrieve compatibility result | Get pass/fail status with details on any incompatibilities (voltage mismatch, current limits, physical fit) |
| JS4 | Check Compatibility | Request compatible replacements | For any incompatible component, get alternatives that would resolve the conflict |
| **JS5** | **Browse Categories** | Request category tree | Retrieve the full or partial category hierarchy |
| JS5 | Browse Categories | Request category products | Retrieve products within a selected category |
| JS5 | Browse Categories | Request category facets | Retrieve the available filter facets for a given category (e.g., motor category → KV range, shaft diameter, weight) |
| **JS6** | **Access Catalog Feed** | Request product catalog export | Retrieve a bulk or incremental catalog feed with full product data |
| JS6 | Access Catalog Feed | Request product availability | Check current availability indicators for a set of product identifiers |
| JS6 | Access Catalog Feed | Request pricing for product set | Retrieve current pricing for a set of products |

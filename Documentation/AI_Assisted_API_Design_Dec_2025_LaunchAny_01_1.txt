GenAI is For More Than Code

Too many organizations are missing out on what AI can really do.

Most organizations today see GenAI as a tool to write more code
faster. While this provides short-term gains, the full potential of
generative AI hasn't been realized.

As GenAI evolves, new capabilities are beginning to emerge.

We explored whether an LLM could act as an API design coach. The
results were impactful.

AI-in-the-loop is the best way to describe this approach. Experts
leverage prompts and LLM automation to accelerate their API design
efforts for critical business systems.

Let's explore what has changed that allows GenAI to assist in the API
design process. We will then explore the ADDR process and how
GenAI can help.

                                                                                                                                                                                                                                                                                                         13
Why Early GenAI Wasn't Ready

Early exploration of API models weren't ready to coach someone
through an API design process. This has recently changed.

Context windows were previously too limiting.
Now, better prompt engineering can overcome this with recent AI models. This
results in reduced hallucinations while avoiding poor or incomplete API designs.

Former LLM models couldn't break down complex workflows.
We now have advanced models that can decompose complex problems into an
executable plan. The plan guides practitioners effectively through the process.
Response outputs were limited to text-based formats.
Recent AI models have added new ways to generate output formats than in the
past. This reduces the manual work required for generating artifacts,
incorporating feedback, and delivering a great API specification.

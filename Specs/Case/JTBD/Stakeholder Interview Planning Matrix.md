# Stakeholder Interview Planning Matrix

| Column | Description |
|--------|-------------|
| **Role** | The stakeholder role being analyzed |
| **What decisions does this role make using product data?** | Key decision areas |

**Group:** Data Producers (Orange)

| Aspect | Details |

## Key Themes Emerging

1. **Transparency** — Most roles want visibility into how data flows and where it's used
2. **Data Quality** — Consistent pain point across producer and curator roles
3. **Cross-system Complexity** — Understanding data meaning across systems is difficult
4. **Manual Overhead** — Many roles maintain manual tracking/mapping tables
5. **Governance Gaps** — Lack of clear ownership and standards enforcement
